# ScoutX

Учебный сайт для поиска и публикации интересных мест.

## Возможности

- Регистрация и вход в аккаунт.
- Просмотр ленты мест с учётом выбранного города.
- Добавление публикаций с описанием и фотографией.
- Просмотр фотографий и комментариев к публикациям.
- Добавление фотографий и комментариев к уже опубликованным местам.
- Сохранение понравившихся мест в избранное.
- Редактирование и удаление собственных публикаций.
- Панель администратора: просмотр пользователей и публикаций, удаление публикаций и добавление категорий.

## Используемые технологии

Java Servlets, JSP, JDBC, PostgreSQL, HTML, CSS и JavaScript.
